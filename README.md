# Snaptube

Snaptube is a free Android app for downloading videos and music so you can watch and listen offline.

## Features

- Download videos in a range of resolutions for offline viewing
- Convert videos to MP3 or M4A audio with one tap
- Built-in search across popular platforms such as YouTube, Facebook, Instagram, TikTok and X
- Download manager with pause, resume and batch downloads
- Lightweight APK that runs well on budget Android phones
